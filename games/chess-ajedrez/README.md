# Ajedrez ♟️

Un juego de ajedrez moderno, interactivo y completamente funcional desarrollado utilizando tecnologías web estándar.
Desarrollado aprovenchando herramientas de IA, practicando el uso de agentes.

## 🛠️ Tecnologías Utilizadas

*   **HTML5** (Estructuración semántica del tablero y paneles)
*   **CSS3** (Estilos modernos, CSS Grid/Flexbox, tipografía Plus Jakarta Sans y variables de diseño)
*   **JavaScript (jQuery 4.0)** (Manipulación del DOM, lógica del juego y cálculo de reglas)

## 🎮 Cómo Jugar

1.  Clona o descarga este repositorio.
2.  Abre el archivo `index.html` directamente en tu navegador web preferido (no requiere servidores locales ni compilación).
3.  **Para mover una pieza:** Haz clic sobre una pieza de tu color (blanco hueso o negro grafito). Se sombreará en amarillo y se mostrarán puntos grises en las casillas a las que puede moverse. Haz clic en el punto de destino para realizar el movimiento.
4.  Si deseas revertir una mala jugada, presiona el botón **Deshacer Movimiento**.
5.  Puedes reiniciar la partida en cualquier momento con el botón **Nueva Partida**.
